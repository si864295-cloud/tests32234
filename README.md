# tests32234 — измерение скорости скачивания

`download_speed.py` последовательно скачивает ответ по HTTP/HTTPS, показывает скорость каждой успешной попытки и итоговую статистику. Данные читаются блоками по 256 КиБ (262 144 байта) и отбрасываются без сохранения на диск.

## Запуск

Нужен Python **3.10 или новее**; работа проверена на Python **3.12.3**. Используется только стандартная библиотека: устанавливать зависимости через `pip` и создавать `venv` не требуется.

```bash
git clone https://github.com/si864295-cloud/tests32234.git
cd tests32234
python3 download_speed.py --url "https://example.org/file.bin" --attempts 5
```

`https://example.org/file.bin` — пример адреса: замените его прямой ссылкой на нужный файл.

Без `--attempts` выполняются 10 загрузок:

```bash
python3 download_speed.py --url "https://example.org/file.bin"
python3 download_speed.py --help
```

## Параметры

| Параметр | Значение | По умолчанию |
| --- | --- | --- |
| `--url` | Обязательный URL со схемой `http://` или `https://` и именем хоста; указанный порт должен быть корректным. | Нет |
| `--attempts` | Положительное целое число последовательных загрузок. | `10` |
| `--timeout` | Конечное положительное число секунд ожидания отдельной сетевой операции. Это не ограничение общего времени загрузки. | `30` |
| `-h`, `--help` | Показать справку и завершить работу. | — |

Например, пять попыток с таймаутом операции 15 секунд:

```bash
python3 download_speed.py --url "https://example.org/file.bin" --attempts 5 --timeout 15
```

## Что измеряется

Каждый запрос выполняется строго после завершения предыдущей попытки. Успешный ответ читается до конца тела. Время попытки включает DNS, установление TCP-соединения, TLS для HTTPS, ожидание ответа сервера и чтение данных. Скорость равна числу полученных байтов тела ответа, делённому на время попытки; заголовки и служебные данные протоколов в объём не входят.

Итоги учитывают только успешные полные загрузки:

- **Общее время запросов** — сумма их длительностей, а не время работы всей программы.
- **Среднее время запроса** — среднее арифметическое этих длительностей.
- **Общий объём скачанных данных** — сумма байтов полностью полученных тел ответов.

Ошибочные попытки подсчитываются отдельно; их время и частично полученные байты в итоговые показатели не входят. Если все попытки завершились ошибкой, общий объём и суммарное время равны нулю, среднее время недоступно.

Пример вывода для двух одинаковых успешных загрузок по 1 МиБ за 0,500 секунды:

```text
[1/2] 1048576 байт (1.00 МиБ), 0.500 с, 16.78 Мбит/с (2.00 МиБ/с)
[2/2] 1048576 байт (1.00 МиБ), 0.500 с, 16.78 Мбит/с (2.00 МиБ/с)
Итого: успешных загрузок — 2, ошибок — 0.
Итоговые показатели учитывают только успешные полные загрузки.
Общее время запросов: 1.000 с
Среднее время запроса: 0.500 с
Общий объём скачанных данных: 2097152 байт (2.00 МиБ)
```

Единицы:

| Обозначение | Значение |
| --- | --- |
| Байт | 8 бит |
| с | Секунды; длительность выводится с тремя знаками после точки. |
| МиБ | 1 048 576 байт (двоичная единица, MiB). |
| Мбит/с | 1 000 000 бит в секунду (десятичная единица). |
| МиБ/с | 1 048 576 байт в секунду (двоичная единица, MiB/s). |

## Ошибки и коды завершения

Результаты и итоговая статистика выводятся в `stdout`, сообщения об ошибках — в `stderr`. После сетевой ошибки программа переходит к следующей попытке. Обрабатываются ошибки DNS, подключения, проверки TLS, таймауты, HTTP 4xx/5xx и неполная загрузка при наличии `Content-Length`; некорректный `Content-Length` также считается ошибкой. Если длина не объявлена, завершённость определяется по окончанию потока.

Проверка сертификатов TLS включена; HTTP-перенаправления обрабатываются стандартной библиотекой автоматически.

| Код | Значение |
| --- | --- |
| `0` | Все загрузки успешны; также штатное завершение `--help`. |
| `1` | Хотя бы одна попытка завершилась ошибкой, включая случай всех ошибочных попыток. |
| `2` | Ошибка параметров командной строки. |
| `130` | Пользователь прервал загрузки через Ctrl+C; итоговая статистика не печатается. |

## Ограничения

Результат характеризует загрузку с конкретного сервера для выбранного размера ответа. На него влияют сервер, маршрут, задержки и размер файла; маленькие ответы особенно чувствительны к затратам на соединение. При полных загрузках объём тел ответов составляет `attempts × размер файла`, дополнительно расходуется служебный трафик.

Запрос содержит `Cache-Control: no-cache`, что не даёт абсолютной гарантии отсутствия влияния кеширования, и `Accept-Encoding: identity`. Содержимое ответа не проверяется: страница с сообщением об ошибке, возвращённая с HTTP 200, считается успешной загрузкой по транспортной логике скрипта.

Скрипт строго типизирован и ранее прошёл `mypy --strict`. `mypy` для запуска не нужен.
